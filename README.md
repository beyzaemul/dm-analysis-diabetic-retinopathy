# Veri Madenciliği Teknikleri Kullanılarak Diyabetik Retinopati Teşhisi

Bu çalışma, Veri Madenciliği dersi kapsamında Diyabetik Retinopati (DR) hastalığının tespiti ve analizi üzerine hazırlanmış bir akademik makale projesidir.

## Makale Hakkında
Bu çalışmada, Diabetic Retinopathy Debrecen veri seti üzerinde çeşitli veri madenciliği teknikleri uygulanarak elde edilen bulgular raporlanmıştır.

* **Yazar:** Elif Beyza Emül
* **Alan:** Sağlıkta Veri Madenciliği

## 🛠 Kullanılan Teknolojiler & Yöntemler
* **Veri Madenciliği Yöntemleri:** Lojistik Regresyon, Naïve Bayes, Decision Tree, k-NN, Yapay Sinir Ağları (ANN) 
* **Araçlar:** Weka
